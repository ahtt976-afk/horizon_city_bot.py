# بوت لعبة الذئب لتطبيق تيليجرام (Werewolf Telegram Bot - Teams Survival Edition)

بوت تيليجرام متكامل باللغة العربية لإدارة لعبة الذئب بنظام الفرق العشوائية داخل المجموعات، مبني بلغة **Python** مع قاعدة بيانات محلية **SQLite3** (`werewolf_local.db`) تُنشأ تلقائياً.

## 🌟 القواعد والمميزات الرئيسية

1. **شرط انتهاء اللعبة والفوز الحصري:**
   - **لا تنتهي اللعبة** عند موت جميع الذئاب أو بقاء القرويين فقط!
   - **تنتهي اللعبة فقط عندما يبقى فريق واحد على قيد الحياة (أو أي عضو منه)** بعد إقصاء جميع الفرق الأخرى.
   - عندما ينتصر الفريق الباقي، **يفوز جميع أعضاء ذلك الفريق** (الأحياء والأموات، حتى لو كان الفريق يضم ذئباً وعرافاً وسفاحاً معاً)، وتخسر جميع الفرق البقية.

2. **عرض أسماء الفرق وأعضائها في المجموعة:**
   - يختار الأدمن في بداية كل جولة حجم الفريق (**2 أو 3 أو 4 أو 5 أو 6 لاعبين**).
   - ينشر البوت تلقائياً في المجموعة **جدول الفرق الكامل وأسماء أعضائها** عند انطلاق اللعبة وفي بداية كل صباح، ليعرف كل فريق الفرق الموجودة وأعضاءها ومن بقي حياً أو قُتل.
   - يمكن لأي لاعب في المجموعة إرسال `/teams` أو `/players` في أي لحظة لعرض قائمة الفرق وأعضائها.

3. **الأدوار الـ 17 المعتمدة حصرياً:**
   - **الذئاب بأنواعها:** الذئب العادي (`Werewolf` 🐺)، ذئب ألفا (`Alpha Wolf` ⚡🐺)، الجرو المدلل (`Wolf Cub` 🐶)، المستذئب المخادع (`Lycan` 🌕🐺).
   - **الدباغ (`Tanner` 👺)**، **الصياد (`Hunter` 🎯)**، **القناص (`Gunner` 🔫)**، **العمدة (`Mayor` 🎖️)**، **العازف (`Pied Piper` 🪈)**، **المسالم (`Pacifist` ☮️)**، **ملاك الحب (`Cupid` 💘)**، **الملاك الحارس (`Guardian Angel` 👼)**، **الكيميائي (`Chemist` 🧪)**، **المحقق (`Detective` 🕵️)**، **العراف (`Seer` 👳)**، **الساحر (`Sorcerer` 🔮)**، **الحداد (`Blacksmith` ⚒️)**، **السفاح (`Serial Killer` 🔪)**، **الأمير (`Prince` 👑)**، **المشاغب (`Troublemaker` 😈)**.
